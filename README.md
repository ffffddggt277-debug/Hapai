# ХАПАЙ! 2.0 — ночное ограбление музея

Браузерная мультиплеерная 3D-игра (вид сверху) на 1–8 игроков. Взламывай витрины, прячься в шкафах от дронов, толкай соперников и выноси добычу через открытый выход раньше остальных.

**Клиент:** Next.js 16 + React 19 + Three.js → Vercel.
**Сервер:** Node.js + Socket.IO (авторитетная симуляция 30 Гц) → Render.

## Что в игре

- **Музей из 7 залов** (44×32 м): галерея живописи, восточная коллекция, сокровищница с короной в центре, док и т. д. 18 витрин трёх типов (стеклянные кубы, постаменты, картины на стенах), 9 шкафов, декор (статуи, скамейки, часы, люстры, камеры, щиты, вентилятор), 4 выхода с фургонами.
- **Ограниченный обзор:** конус 105° и 9 м в сторону взгляда, стены закрывают видимость (туман войны в шейдерах + маска видимости). Сервер не присылает координаты тех, кого ты не видишь.
- **Взлом удержанием:** подойди к витрине и держи E (на телефоне — кнопку «Действие»). Кольцо прогресса, трещины, осколки стекла. На 45% взлома срабатывает **сирена**, и **2–3 дрона летят на звук**.
- **Дроны:** патруль → вылет на сирену → погоня → поиск. Если поймают — оглушение 2 с и вся добыча падает мешком на пол (её может подобрать кто угодно).
- **Шкафы:** зайди в шкаф — двери открываются/закрываются с анимацией, ты невидим **5 секунд**, дроны теряют след. Перезарядка 7 с.
- **Толчок** (−50% добычи соперника, она выпадает мешком) и **рывок**.
- **Выходы меняются** каждые 36 с, в финале (последние 30 с) открыт только погрузочный док.
- **Персонаж** — мини-грабитель в маске (присланная модель `thief.glb`) с анимациями: ходьба (оригинальная), стойка, бег, взлом, толчок, рывок, оглушение, прятки, радость, поимка — сделаны в Blender на его скелете.
- **Ники над игроками**, цветное кольцо и повязка, мешок на спине растёт с добычей.
- **Интерфейс как в играх:** главное меню с 3D-сценой, лобби с ворами вокруг короны, HUD (рюкзак, таймер, выход, лидерборд, мини-карта, лента событий, способности с перезарядкой), баннер тревоги, оверлей шкафа, экран «ПОЙМАН», пьедестал результатов, пауза и настройки (громкость, музыка, графика).
- **Звук:** синтезированная шпионская музыка (ускоряется в финале), сирена, звон стекла, касса, гул дронов.
- **Боты** для тренировки или для заполнения комнаты.

## Управление

| ПК | Телефон |
|---|---|
| WASD / стрелки — движение | левый стик |
| Мышь — куда смотреть | свайп по правой части экрана (или направление движения) |
| **E удерживать** (или ПКМ) — взлом / шкаф | кнопка «Действие» (удерживать) |
| ЛКМ / F / Q — толчок | кнопка «Толчок» |
| Space / Shift — рывок | кнопка «Рывок» |
| Esc — пауза | ⏸ |

## Локальный запуск

Нужен Node.js 22+ и npm.

```bash
npm ci
npm run dev:server      # http://localhost:10000/health
npm run dev:client      # http://localhost:3000 (во втором терминале)
npm test                # тесты карты и сервера
npm run build           # production-сборка клиента
```

Открой `http://localhost:3000` в двух вкладках: в первой «Играть с друзьями», во второй введи код комнаты. Или «Тренировка с ботами».

## Деплой

Подробно — в [DEPLOY.md](DEPLOY.md). Коротко: сервер — Render (Blueprint из `render.yaml`), клиент — Vercel (Root Directory `apps/client`, переменная `NEXT_PUBLIC_SERVER_URL`), на Render задать `FRONTEND_URL`.

## Структура

```text
apps/client/app/          Game.tsx (интерфейс), engine.ts (3D), audio.ts (звук), style.css
apps/client/public/models/ 31 GLB-модель (оптимизированы в Blender)
apps/server/index.mjs     игровой сервер: комнаты, дроны, боты, взлом, шкафы
packages/shared/world.mjs карта, коллизии, видимость, маршруты (общие для клиента и сервера)
blender/                  скрипты Blender 4.5 LTS: анимации вора, сборка моделей
tests/                    node:test — карта и реальный мультиплеер
media/                    трейлер и скриншоты
```

## Ограничения

- Комнаты хранятся в памяти одного процесса: рестарт/деплой сервера обнуляет матчи. Запускать один экземпляр.
- Бесплатный Render засыпает после 15 минут без запросов — первый вход после сна занимает ~1 минуту (игра покажет сообщение).
- Нет аккаунтов, рейтинга и чата. На реальных iOS/Android не проверялось — только эмуляция в Chromium.
